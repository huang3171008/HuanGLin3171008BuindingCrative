# 猜拳小擂台 · Huang-Lin1008 Guessing

一款手机优先的双人猜拳游戏。玩家通过房间码加入同一局游戏，选择角色、出拳并获得虚拟金币。包含 10 回合普通模式、竞猜对方手势和竞猜输赢三种玩法。

## 项目内容

- `game/`：网页、房间服务与 SQLite 金币数据库。需要 Node.js 24 LTS，无第三方运行时依赖。
- `android/`：Android 客户端源码，支持配置 HTTPS 游戏服务器地址。

金币只是游戏内虚拟积分，不支持充值或提现。本项目是小规模自托管版本：玩家身份保存在浏览器或应用中，清除数据会丢失身份；它没有完整账号、防刷或生产环境风控系统。**请勿用于真实货币或有价值物品的交易。**

## 本机运行

```bash
cd game
node build.mjs
node server.mjs
```

使用同一台电脑的浏览器打开 `http://127.0.0.1:3000`。默认监听地址仅对本机开放，数据保存在 `game/data/game.sqlite`。停止服务按 Ctrl+C。

可设置环境变量 `PORT`、`HOST` 和 `GAME_DATA_DIR`。对外使用时应配置受信任的 HTTPS 证书、反向代理和数据备份；公网服务器所在地区的接入及备案要求请向服务商确认。手机应用的“服务器”入口只接受 HTTPS。

```bash
node check.mjs
```

自检会在本机启动临时服务，模拟双方加入、出拳、竞猜以及服务重启后的钱包保存。它不会验证公网或各地区网络的可达性。

## 安卓客户端

构建说明见 [android/README.md](android/README.md)。客户端加载服务器上的网页；安装 APK 并不会自动提供服务器。两台手机需连接同一个可访问的服务器。

## 数据迁移

新部署默认创建全新数据库。旧站的数据不会通过钱包迁移码自动复制：需要管理员先迁移数据库并验证，再由玩家导入身份。数据库、钱包迁移码、服务器凭据和安卓签名密钥都不应上传到公开仓库。
