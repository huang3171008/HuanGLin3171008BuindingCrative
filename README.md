# 猜拳小擂台 · Huang-Lin1008 Guessing

> 云端房间升级为开发测试版本：新增独立 WebSocket 权威房间服务、8 位数字房间码、准备、可选公开搜索与短线恢复。尚未部署国内服务器，尚未通过真实跨设备和 iOS 测试，不要当作正式上线版本。搭建与测试见 [云端房间测试说明](game/云端房间测试说明.md)。原直连玩法保留；云端钱包与直连钱包分开。

一款手机优先的双人猜拳游戏。玩家通过房间码加入同一局游戏，选择角色、出拳并获得虚拟金币。包含 10 回合普通模式、竞猜对方手势和竞猜输赢三种玩法。

## 项目内容

- `game/`：网页、房间服务与 SQLite 金币数据库。需要 Node.js 24 LTS，无第三方运行时依赖。
- `android/`：Android 客户端源码，支持同一 Wi-Fi／热点的局域网直连、不同网络手动交换信息的 WebRTC 直连，以及原有 HTTPS 服务器模式。

金币只是游戏内虚拟积分，不支持充值或提现。本项目是小规模自托管版本：玩家身份保存在浏览器或应用中，清除数据会丢失身份；它没有完整账号、防刷或生产环境风控系统。**请勿用于真实货币或有价值物品的交易。**

## 本机运行

```bash
cd game
node build.mjs
node server.mjs
```

使用同一台电脑的浏览器打开 `http://127.0.0.1:3000`。默认监听地址仅对本机开放，数据保存在 `game/data/game.sqlite`。停止服务按 Ctrl+C。

可设置环境变量 `PORT`、`HOST` 和 `GAME_DATA_DIR`。对外使用时应配置受信任的 HTTPS 证书、反向代理和数据备份；公网服务器所在地区的接入及备案要求请向服务商确认。手机应用的“服务器”入口只接受 HTTPS。

```bash
node check.mjs
```

自检会在本机启动临时服务，模拟双方加入、出拳、竞猜以及服务重启后的钱包保存。它不会验证公网或各地区网络的可达性。

## 安卓客户端

构建说明见 [android/README.md](android/README.md)。客户端内置直连界面；局域网由房主临时创建连接码，不同网络需双方通过聊天工具交换较长的邀请和回复信息。跨网络直连使用公共 STUN 服务辅助发现地址，不使用 TURN 中转；部分网络无法建立连接。原服务器模式仍需要两台手机访问同一个服务器。直连钱包保存在各自手机上，与服务器钱包分开，房主负责结算，无法防止修改客户端作弊。

## 数据迁移

新部署默认创建全新数据库。旧站的数据不会通过钱包迁移码自动复制：需要管理员先迁移数据库并验证，再由玩家导入身份。数据库、钱包迁移码、服务器凭据和安卓签名密钥都不应上传到公开仓库。

## 多端升级

- Android：局域网和不同网络直连、金币流水、10 个角色、四种主题及两段可选音乐。
- Windows：`desktop/` 为独立桌面客户端，可与同版本安卓客户端连接，也可打开原服务器模式。
- iPhone / iPad：`ios/` 为 Xcode 工程；本项目在 Windows 上开发，苹果工程尚未使用 Xcode 或实体设备验证。
- 连接信息使用 `GUESS2` 协议，与早期版本不兼容，请双方升级。

直连模式的金币变化记录在本机；服务器页面也有本浏览器的金币流水和玩法教程，两种模式的数据分开。画面和音乐设置目前用于直连版。清除应用数据会丢失本机金币和记录。

游戏界面内可点击“玩法教程”查看三种模式；更详细的安装和联机步骤见 [使用教程](使用教程.md)。
