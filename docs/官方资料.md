# 中国大陆跨平台联网：官方资料核验

核验日期：2026-11-24。本文是 P0/P1 调研，不代表已购买服务、获得资质、部署或通过真机验证。价格动态变化，最终订单、续费条件和资质以提供商及主管部门为准。

## 1. Photon 的真实能力与大陆区限制

- [Photon 区域官方文档](https://doc.photonengine.com/realtime/v5/connection-and-authentication/regions) 将 Chinese Mainland `cn` 列为上海；大陆区需联系 Photon 为相应 AppID 开通；大陆付费订阅不能直接在普通控制台购买，需工单询价；大陆名称服务器是 `ns.photonengine.cn`。官方说明中国市场需要单独构建，建议不同 AppID；在大陆使用跨境自定义认证或 Webhooks 可能不可靠。AppID 类型必须匹配 SDK。
- [Photon Realtime 定价](https://www.photonengine.com/realtime/pricing) 列出 20 CCU 免费开发档（60GB/月，仅开发，不能用于正式发布）；这是全球公共价格信息，**不能据此保证中国大陆区可免费开通或适用相同条件**。大陆区的免费额度、地区权限、支付金额及商业条款须以 Photon 书面答复为准。
- [Photon Realtime Core JavaScript 文档](https://doc.photonengine.com/realtime-core/v6/bindings/javascript-typescript-api) 确认提供 JS/TS 浏览器支持：Web 使用 WSS/WS，默认 WSS；浏览器构建没有原生 UDP/TCP、不能自动 ping 选最佳区域。尚未验证用户的 Android WebView、iOS WKWebView、Electron 和大陆区在对应 SDK 版本的组合，也未验证其 CN AppID 或价格。
- [Photon 产品说明](https://doc.photonengine.com/photon/current/photon-products) 将 Realtime 定位于房间、匹配、消息中转/Webhooks 等低层服务；**不能仅凭有房间与中转功能就声称服务端已替游戏保密出拳、独立计分**。为了服务端权威结算仍需确认云插件/回调的可用权限及安全边界，或单独维护权威逻辑服务。[Photon 插件手册](https://doc.photonengine.com/server/v5/plugins/manual) 指出自定义插件只适用于 Enterprise Cloud 或自行部署 Photon Server；[Webhook FAQ](https://doc.photonengine.com/realtime/v5/gameplay/web-extensions/webhooks-faq) 描述服务端代码和事件授权用途，具体大陆套餐支持、同步校验及保密条件须与供应商确认。Fusion 的 Unity 生态并不证明可直接复用现有网页；更不应为了它先改写成 Unity。
- [Photon 端口说明](https://doc.photonengine.com/realtime/v5/connection-and-authentication/tcp-and-udp-port-numbers) 列示安全 WebSocket 可能涉及 443 或 19090/19091/19093 端口；不同版本和地区具体地址、端口由实际 SDK 与 Photon 确认。校园网即使开放 443 也可能经过代理、阻断 WSS 升级或域名策略，无法保证全部可用。

## 3. 中国大陆网络、出版与个人信息

- [工信部 APP 备案通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)：在境内从事互联网信息服务的 APP 主办者，应按规定备案，未履行备案不得从事 APP 互联网信息服务；新业务需先备案再开展。**不能笼统断言“仅朋友测试必然免备案”**；内测范围、域名、接入方式和服务性质应先咨询所在地通信管理局与云服务商。
- 网站/域名接入内地机房及 APP 分发属于不同对象；已有网站备案不自动等于 APP 备案。经营性与非经营性 ICP 许可/备案也不同。[腾讯云首次备案指引](https://cloud.tencent.com/document/product/243/97668) 说明面向公网的服务、公安联网备案和有条件例外；其“仅 API 无网页”的网站例外不能自动推广为 APP 免公安备案，具体先向属地主管部门核实。
- [国家新闻出版署国产网络游戏出版审批](https://www.nppa.gov.cn/bsfw/xksx/cbfxl/wlcbfwspsx/202210/t20221013_600725.html) 列明出版单位资质、作品权属、运营机构 ICP 证和未成年人保护等条件，省级初审后报国家新闻出版署。适用范围和实际申报路径需结合公开运营、游戏内容及主体进行确认；不能把 MIT 开源或未收费等同于无版号要求，也不承诺个人主体可独立取得全部所需资质。
- [国家新闻出版署防沉迷解读](https://www.nppa.gov.cn/xxgk/zcjd/202108/t20210830_4759.html) 阐述实名及未成年人时段限制要求，适用商业游戏网络服务需和具体运营主体、主管部门确认。研发时最小化不必要个人信息，并不是公开运营可以直接免实名的结论。
- [《个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm) 要求合法正当必要、明示处理和最小范围；IP、会话令牌等是否为个人信息需结合可识别性判断，日志中应避免完整令牌、出拳秘密、精确 IP 等；真实账号、实名或支付信息如需处理应单独设计并评估。
- 现有玩法含金币投入、奖励转移与“赌局”表述；**不能仅凭虚拟币名称判断违法或合规**。有无充值、兑换、转让、现实价值、未成年人及实际运营等会影响认定。正式公开发布前与主管部门、出版方和熟悉游戏合规的专业人士核对；不宜自动加入真钱充值、兑换或交易。可参考[文化和旅游部门虚拟货币管理文件](https://zwgk.mct.gov.cn/zfxxgkml/zcfg/gfxwj/202012/t20201204_906151.html)，并核验当前有效性与具体适用。

## 4. 苹果、Windows、Android 发行成本及约束

- [Apple Developer 官方项目](https://developer.apple.com/programs/)：免费 Apple 账户可使用 Xcode 在自己的设备上直接测试，受能力和签名条件限制；[付费计划](https://developer.apple.com/help/account/membership/program-enrollment) 为 99 美元/会员年，实际本地币结算因地区而异，TestFlight/App Store 分发按账户、证书、审核等要求实施。Xcode、macOS、Apple 设备和签名条件是现实交付门槛；本次未构建或签名 iOS 包。
- Windows、Android 的本地开源工具本身可不购买商业 SDK；Windows 代码签名证书、Android 分发渠道账号/上架、独立真机与维护均可能有费用，尚无特定报价。免费 APK 不意味着具备公开运营条件。安卓 AAB 只是发行构建格式，渠道是否接受及签名由目标渠道确定。

## 5. 推荐与待核事项

推荐以中国大陆自建小型 WSS 服务器为主线做实施前设计：客户端主动走 TCP 443/HTTPS 升级，在同 Wi-Fi 和不同网络共享同一房间系统，权威房间/出拳/积分由服务端执行；国内 DNS、证书、机房、资质与真实校园网测试仍是门槛。先用测试设施验证三端，再由用户决定账号、云费、域名和上线；本阶段不下单不部署。

Photon 作为候选，只有在官方确认 `cn` 开通条件、JS/WSS/WebView 能力、服务器侧保密权威结算、隐私与价格之后才能做等价比较。用户最终任何网络均成功的诉求只能写成测试目标，不能保证所有防火墙、代理和运营商都允许长连接。
